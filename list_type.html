Ordered List

Let's learn about Ordered List:- An ordered list in HTML is used when the sequence or order of the items is important. It is created using the `ol` tag, and each item is defined using the `li` tag. By default, the items are displayed with numbers. For example - List of Names of Fruits

  1. Kiwi
  2. Apple
  3. Banana
  4. Orange
  5. Strawberry

This is done with default type 1. There are total 5 types for orders. 1(Default), A, a, I, i. We can specify the order type by giving type attribute in opening tag of `ol` tag

Unordered List

Let's learn about Unordered List:- An unordered list in HTML is used when the order of the items does not matter. It is created using the `ul` tag, and each item is defined using the `li` tag. By default, the items are displayed with bullet points. For example - List of Names of Friends

  • Prachi
  • Swaraj
  • Priya
  • Mohit
  • Shrushti
  • Aryan

This is done with default type disc. There are total 4 types for orders. disc(Default), Circle, Square and none. We can specify the order type by giving type attribute in opening tag of `ol` tag

Definition List

Let's learn about Definition List:- A definition list in HTML is used to display a list of terms and their corresponding definitions. It is created using the `dl` tag, with each term defined using the `dt` tag and each definition defined using the `dd` tag. For example - List of Names of Fruits with their information

Kiwi
Kiwi is a small, oval-shaped fruit with brown, fuzzy skin and green flesh containing tiny black seeds. It has a sweet and slightly tangy taste.
Apple
Apple is a round fruit that comes in different colors such as red, green, and yellow. It has a sweet or slightly sour taste and is commonly eaten raw.
Banana
Banana is a sweet and nutritious fruit that is rich in potassium, fiber, and vitamins. It provides quick energy and supports healthy digestion.
